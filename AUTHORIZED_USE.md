# Authorized use

This repository is a restricted local cyber range for security research,
remediation validation, and education.

Run the reproducer only against the included loopback labs. The released client
enforces the documented loopback hosts and lab ports, rejects arbitrary command
input, and requires fresh proof before reporting success.

Do not use this material to access or disrupt third-party systems, acquire
third-party data or credentials, establish persistence, evade controls, or
perform any activity without explicit authorization.

`profiles.json` is retained to identify exact builds, preserve provenance, and
keep compatibility claims reproducible. A profile entry is not authorization
to test another system.
